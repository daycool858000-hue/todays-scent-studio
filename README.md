# 你今天的味道｜虛擬調香所

這是一個可以把氣味、情緒、食物、生活片段和記憶混合起來的虛擬調香遊戲。

選擇想放進容器的素材，觀察光影、泡泡與液體如何融合；完成後可以閱讀專屬氣味的前中後調、感受與故事，並自行命名、收藏或下載香氣卡。

## 開啟網站

網站正式發布後，入口為：
https://daycool858000-hue.github.io/todays-scent-studio/

## 維護與存取

- 網站程式放在本儲存庫根目錄的 `index.html`，使用 GitHub Pages 免費靜態發布。
- 不需要登入。已儲存的香氣通常存在目前瀏覽器的本機儲存空間，不會跨瀏覽器、跨裝置或跨網域自動同步。
- 網站呈現的是虛擬香氣藝術與互動遊戲，不是可直接製作的實體香水配方。
- 內部規劃、未公開素材、密碼及憑證不要上傳到公開儲存庫。
- 原先的歷史測試版本暫時保留在舊儲存庫中；後續新版以此儲存庫維護。
